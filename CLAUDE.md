# Репозиторий `leadfinish` — навигация для AI-агента

Здесь только указатели и правила уровня репозитория. Содержательные памятки
лежат рядом — читай их, а не пересказывай по памяти.

| Читай | Когда |
| --- | --- |
| `shef.leadfinish/CLAUDE.md` | **перед любой правкой кода модуля**: опорные точки в ядре, ловушки, решения владельца |
| `shef.leadfinish/README.md` | когда нужно понять процесс глазами менеджера |
| `CONTRIBUTING.md` | перед коммитом, PR и мержем |
| `docs/module-structure.md` | когда добавляешь файлы, классы, ajax-действия, настройки |
| `docs/build-and-install.md` | когда собираешь архив или объясняешь установку |
| `build.sh` | проверки и сборка; CI (`.github/workflows/ci.yml`) вызывает его же |
| `tests/` | тесты чистой логики — всё, что проверяется без рантайма Битрикса |

## Действует во всём репозитории

- Общаемся, документируем и комментируем код **по-русски**. Код — в стиле
  Битрикса: табы, аллмановские скобки.
- **В `main` не пушим.** Работа — в отдельной ветке, изменения — через PR,
  мержит владелец сам.
- **Ядро Битрикса не правим:** ни одного файла в `bitrix/`. Интеграция — только
  через публичные события и универсальное API CRM.
- **Права проверяем всегда** — и на показ кнопки, и в ajax-действии. Спрятать
  кнопку мало: адрес действия известен из кода и вызывается напрямую.
- **Главная проверка — приёмочный чек-лист** из `shef.leadfinish/CLAUDE.md`: почти
  всё завязано на рантайм Битрикса. Он обязателен перед мержем.
- **Чистую логику покрываем тестами** в `tests/` — то, что видно без портала:
  разбор настроек, нормализация, матрицы решений. Меняешь такие правила — правь
  тест в том же PR.
- Перед сдачей — `./build.sh --check` (`php -l`, `node --check`, регистр имён в
  `lib/`, тесты). Ровно это гоняет CI на каждый PR.
- Версию в `shef.leadfinish/install/version.php` поднимаем при каждом изменении
  поведения. Релиз — кнопкой **Actions → Release → Run workflow** от `main` либо
  тегом `vX.Y.Z`; тег обязан совпадать с `VERSION`.

## Чего не делать

Решения владельца, записанные в `shef.leadfinish/CLAUDE.md` (перезапись чужой
связи, пустой `allowed_users` = всем, поиск только по названию, период 7 дней),
— это решения, а не баги. Не «чини» их и не переигрывай без явной просьбы.

Отдельно: у модуля **нет страницы настроек в админке**, и это тоже решение.
`allowed_users` живёт в `.settings.php`; возвращать настройку в базу — значит
завести второй источник той же правды.
